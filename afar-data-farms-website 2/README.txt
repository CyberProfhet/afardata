AFAR DATA FARMS WEBSITE
======================

Files
-----
index.html     Home page
about.html     About, mission, vision, values and work areas
services.html  Detailed service areas
blog.html      Knowledge hub / planned content themes
contact.html   Contact details and enquiry form
style.css      Shared styling and responsive layout
script.js      Mobile navigation and small form checks

HOW TO PREVIEW
1. Keep all files in the same folder.
2. Open index.html in your browser.
3. Use the top navigation to open the other pages.

IMPORTANT BEFORE PUBLISHING
- The official Afar Data Farms logo is included at images/afar-logo.png.
- Photos currently load from Unsplash URLs and therefore require an internet connection. Replace them with approved company photos when available.
- The contact form uses FormSubmit (a third-party service). Test and activate the form before launch.
- Confirm the Instagram URL before publishing.
- The Blog page contains planned content themes, not claims of published research.
- No unverified impact statistics have been added.

BRAND NOTES
The design uses the brand guide's green, forest, pale-green, earth and orange palette and an educational, trustworthy tone. Font fallback is included; the guide's Gilroy font can be added if you have a licensed web font file.
