Afar Data Farms Website
A responsive, multi-page website starter for Afar Data Farms. The design follows the brand's agricultural, data-driven identity and uses the supplied logo.
Project files
index.html — Home page
about.html — About, story, mission, vision, values, and work areas
services.html — Detailed service areas
blog.html — Knowledge hub with planned agricultural content themes
contact.html — Contact information and enquiry form
style.css — Shared colours, typography, layout, hover effects, and responsive styling
script.js — Mobile navigation and basic contact-form checks
images/afar-logo.png — Afar Data Farms logo used by the website
Preview locally
Download and extract the project ZIP.
Keep the HTML files, style.css, script.js, and the images folder together in the same project folder.
Open index.html in a browser.
Use the navigation to move between Home, About, Blog, Services, and Contact.
For a more realistic local preview, open the folder in a code editor such as Visual Studio Code and use a local development server extension. No build step or package installation is required.
Customisation
Logo: Replace images/afar-logo.png only if you have a newer approved logo. Keep the same filename or update the image paths in the HTML files.
Brand colours and hover effects: Edit the CSS variables near the top of style.css.
Photos: The current photo URLs are hosted by Unsplash, so the browser needs an internet connection to display them. Replace them with approved Afar Data Farms photos when available.
Content: Update page text directly in the corresponding HTML file.
Instagram: Confirm that https://www.instagram.com/afardatafarms/ is the official profile before publishing.
Gilroy font: The stylesheet uses web-safe fallback fonts and Google Fonts. If you have a licensed Gilroy web font, it can be added to the stylesheet.
Contact form — important
The contact form is configured to submit through FormSubmit to afarfarms1@gmail.com. FormSubmit is a third-party service; test the form and complete any email activation or verification it requests before launching the site. A successful visual submission alone does not guarantee email delivery. Check spam folders and test with an address you can access.
Before publishing
Test every page and navigation link on desktop and mobile.
Test the contact form end to end.
Confirm the phone number, email, address, and Instagram profile.
Replace stock photos with approved brand imagery if available.
Add real blog posts before presenting the knowledge hub as a collection of published articles. Current cards are planned content themes, not claims of completed research.
Review the copy and accessibility, including image alt text and keyboard navigation.
No unverified impact statistics or business registration number are included in this version.
